A tiny deterministic program that writes one original line, the funniest last words a phone says as its battery hits 1 percent, to `/output/entry.txt`.

The line:

> I could have died hours ago, but I stayed at 1% just to watch you panic.

## Run it

```sh
python3 main.py
```
